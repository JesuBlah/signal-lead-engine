# Data

`live-advertisers-verified.csv` is the real output of our prototype: 164 Finnish companies our
pipeline marked as `LIVE_CONFIRMED` (advertising on Google at the time of the run).

Use it for the advertiser identity work described in the main README, section 4. Compare the
`company` column against `google_advertiser_name` and you will see the problem immediately.

Contact details (email, phone) and revenue figures are deliberately left out. They are not needed
for this work and there is no reason to hand them around.

Treat this file as confidential. These are real companies we are contacting.
